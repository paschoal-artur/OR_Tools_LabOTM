# Projeto OR-Tools — Modelagem e Otimização

## Requisitos

- Python 3.9+
- pip

## Instalação

```bash
pip install -r requirements.txt
```

## Execução

```bash
python main.py
```

Ao iniciar, um menu numerado permite selecionar qualquer
um dos 8 casos. Cada caso exibe os dados, resolve o modelo
com OR-Tools e responde as perguntas solicitadas.
